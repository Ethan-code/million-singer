# 百萬大歌星

KTV 式接唱遊戲。歌詞像 KTV 一樣逐字跑，唱到被遮住的那一整句自動停下，輪到的隊伍接唱，答對拿分（還藏著的字數 × 100），最後上頒獎台。

- **舞台視窗**給觀眾看（3D 舞台、遮字翻牌、計分板），永遠不顯示答案。
- **控制台視窗**給操作者：管理題庫、編輯歌曲、遊戲中看答案與操作。
- **手機遙控**給主持人：掃 QR code 看答案、判定、計分。

完整功能與設計取捨見 [docs/features.md](docs/features.md)，版本紀錄見 [CHANGELOG.md](CHANGELOG.md)。

## 快速開始

1. 開啟 app，控制台左側選題庫（第一次會有範例）。
2. 下方填隊伍名稱（不計分就留空），按「▶ 開始遊戲」。
   - 有第二個螢幕：舞台自動開在那裡並全螢幕。
   - 只有一個螢幕：舞台另開視窗，按 F 全螢幕。
3. Space 播放。唱到遮字句會自動停下，輪到的隊伍接唱整句：
   - 答對按 Enter（自動加分），答不出來按 A 公布答案。
   - 參賽者可以要求提示（I，翻開一個字、少 100 分）或重聽（B）。
   - 全部唱完按 P 公布結果。
4. 需要主持人用手機看答案：控制台右上「📱 手機遙控」→ 開啟 → 手機掃 QR code（手機和電腦要在同一個 Wi-Fi）。

## 歌曲與題庫放哪

預設在「文件」底下的 `MillionSinger` 資料夾：

```
MillionSinger/
  songs/       音檔（mp3 等）
  playlists/   題庫 .json
```

控制台頂部可以「開啟」資料夾，或「變更」成其他位置（例如雲端硬碟、隨身碟）。每次存檔前舊題庫會備份到 `playlists/.backup/`。

> 從 v1 升級：v1 的歌曲和題庫在 app 內部，請把原本的 `songs/`、`playlists/` 內容複製到上面的資料夾。

# 出題指南

建議用控制台的**歌曲編輯器**出題（題庫裡按「新增歌曲」或「編輯」）：

1. 填歌名、歌手。
2. 設定音源：「選擇音檔…」（會複製進 `songs/`）或貼 YouTube 網址。
3. 帶入歌詞：「線上搜尋」「匯入檔案」或「貼上」。簡體歌詞按「简→繁」。
4. 對時間：
   - 歌詞已有時間：播放聽聽看，整首偏掉就用「全部平移」。
   - 歌詞沒有時間：按「打拍子模式」，播放時每句開唱按 Space。
5. 在要遮的那一行按 ★（或 M）整句遮起來；只想遮幾個字就先選取再按 ★。
6. **只有遮字句的時間要精準**：選那一行，按 🎯（或 T）試停。
   - 聽到答案的第一個音 → 按 `[` 把時間調早
   - 前一句被切掉太多 → 按 `]` 調晚
   - 有本地音檔時可以看波形，點波形直接設定時間。
7. 設定開始／結束時間，按「儲存」。

app 會在遮字句時間的 **0.1 秒前**停下，避免漏出答案的第一個音。

## 題庫格式

不用編輯器也可以直接改 JSON。一個題庫是 `playlists/` 裡的一個 `.json` 檔，內容是歌曲陣列，每首歌是一個 Round：

```json
[
  {
    "title": "歌名（揭曉時顯示）",
    "artist": "歌手",
    "filename": "song.mp3",
    "youtube": "影片 ID 或網址",
    "youtubeOffset": 1.25,
    "startTime": 11,
    "endTime": 80,
    "lrc": ["[00:20.92] 一般的歌詞", "[01:00.41] *一心一德*貫徹始終"]
  }
]
```

| 欄位 | 說明 |
|---|---|
| `title` | 歌名，揭曉答案時滑出顯示 |
| `artist` | 歌手（選填） |
| `filename` | `songs/` 裡的音檔檔名 |
| `youtube` | YouTube 影片 ID（選填，可和 `filename` 同時設定） |
| `youtubeOffset` | YouTube 版本比歌詞時間晚幾秒（選填） |
| `url` | 音訊網址（選填） |
| `startTime` / `endTime` | 播放範圍（秒），`endTime` 省略或 0 為播到底 |
| `lrc` | 歌詞，每句一行 `[分:秒.百分秒] 歌詞`；用 `*` 包住要遮的字 |

- 超過 60 秒要進位成分鐘：寫 `[01:00.41]`，不要寫 `[00:60.41]`。
- 遮字顯示成翻牌：中文一個字一張，英文一個單字一張。

# 開發

```bash
mise install        # Node 24（見 mise.toml）
npm install
npm start           # 開發模式
npm test            # 單元測試
npm run build:win   # 或 build:mac / build:linux
```

# Mac
## 法一
請執行以下指令繞過檢查
```
sudo xattr -cr /path/to/百萬大歌星.app
```

> 把 App 拖進終端機就可以自動填入路徑

## 法二
或者比較簡單的方式：
1. 對著 App 按 右鍵。
2. 按住鍵盤的 Option (或 Control) 鍵不放。
3. 點選 「打開」。
4. 在跳出的視窗中再點一次 「打開」。

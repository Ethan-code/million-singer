# 歌曲與題庫放哪

歌曲和題庫放在 app 外面的資料夾，預設是：

- macOS：`~/Documents/MillionSinger`
- Windows：`文件\MillionSinger`

```
MillionSinger/
  songs/       音檔（mp3 等）
  playlists/   題庫 .json，題庫裡的 filename 指向 songs/ 內的檔名
```

第一次開啟 app 時會自動建立這個資料夾並放入範例。開始畫面下方可以「開啟」資料夾，或「變更」成其他位置（例如雲端硬碟、隨身碟）。

> 從舊版升級：舊版的歌曲和題庫在 app 內部，請把原本的 `songs/`、`playlists/` 內容複製到上面的資料夾。

# 出題指南

## 題庫格式

一個題庫是 `playlists/` 裡的一個 `.json` 檔，內容是歌曲陣列，每首歌是一個 Round：

```json
[
  {
    "title": "歌名（揭曉時顯示）",
    "filename": "song.mp3",
    "startTime": 11,
    "endTime": 80,
    "lrc": [
      "[00:20.92] 一般的歌詞",
      "[01:00.41] *一心一德*貫徹始終"
    ]
  }
]
```

| 欄位 | 說明 |
|---|---|
| `title` | 歌名，揭曉答案時滑出顯示 |
| `filename` | `songs/` 裡的音檔檔名（也可改用 `url` 指定完整網址） |
| `startTime` | 從第幾秒開始播，省略為 0 |
| `endTime` | 播到第幾秒結束，省略或 0 為播到底 |
| `lrc` | 歌詞，每句一行 `[分:秒.百分秒] 歌詞` |

## 歌詞與遮字

- 時間格式是 `[mm:ss.xx]`，超過 60 秒要進位成分鐘：寫 `[01:00.41]`，不要寫 `[00:60.41]`。
- 用 `*` 把要遮的字包起來，該句就是一個遮字題：`*一心一德*貫徹始終`。一句可以有多段 `*…*`。
- 遮字顯示成 ★：中文一個字一顆星，英文一個單字一顆星。
- 唱到遮字句前 5 秒會出現紅框警示，到遮字句會自動停住，主持人按 Enter（答對）或 A（公布答案）後繼續播放。

## 校正遮字句的時間

只有**遮字句**的時間需要精準，其他句子大概對就好。app 會在遮字句時間的 **0.1 秒前**停下，避免漏出答案的第一個音。

1. 用能看波形的軟體（例如 Audacity）打開音檔，找到遮字句**第一個字開口的瞬間**，記下時間（精確到 0.01 秒），寫進 `lrc`。
2. 暫時把 `startTime` 設成遮字句前約 5 秒，在 app 裡試播：
   - 聽得到答案的第一個音 → 時間**減** 0.05 秒
   - 前一句被切掉太多 → 時間**加** 0.05 秒
3. 改完 JSON 後回首頁（H）重新選題庫，或按 `Ctrl+R` 重新整理，就會讀到新內容。
4. 調好後把 `startTime` 改回來。

# Mac
## 法一
請執行以下指令繞過檢查
```
sudo xattr -cr /path/to/百萬大歌星.app
```

> 把 App 拖進終端機就可以自動填入路徑

## 法二
或者比較簡單的方式：
1. 對著 App 按 右鍵。
2. 按住鍵盤的 Option (或 Control) 鍵不放。
3. 點選 「打開」。
4. 在跳出的視窗中再點一次 「打開」。

# 功能文件（v2.1）

這份文件描述目前做出來的版本有哪些功能、怎麼運作、做了哪些取捨，供之後討論要保留、修改或刪除什麼。玩法設計的理由在 [game-design.md](game-design.md)，需求討論的歷史在 [redesign-plan.md](redesign-plan.md)，版本差異在 [CHANGELOG](../CHANGELOG.md)。

## 一句話

KTV 式接唱遊戲：歌詞像 KTV 一樣逐字跑，唱到被遮住的那一整句自動停下，輪到的隊伍接唱，答對拿分（還藏著的字數 × 100）。分成「觀眾看的舞台」與「操作者／主持人看的答案區」。

## 角色與畫面

| 畫面 | 給誰看 | 內容 | 看得到答案？ |
|---|---|---|---|
| **舞台視窗** | 觀眾（投影、電視） | 3D 舞台、歌詞、遮字翻牌、計分板 | ❌ 永遠不會 |
| **控制台視窗** | 操作者 | 題庫管理、歌曲編輯器、遊戲操作面板 | ✅ |
| **手機遙控** | 主持人 | 答案、判定按鈕、計分 | ✅ |

畫面組合由使用者依場景決定，不寫死模式：

- **延伸螢幕**（投影）：舞台自動開在第二個螢幕並全螢幕；控制台留在筆電。
- **單一螢幕**（家裡電視）：舞台另開一個視窗，按 F 全螢幕；用鍵盤操作，主持人用手機看答案。
- 主持人與操作者可以是不同人：主持人拿手機判定，操作者在控制台控制播放。

## 遊戲流程

```
控制台：選題庫 → 自動檢查 →（填隊伍、選音源偏好）→ 開始遊戲
舞台：  ROUND N 開場（3D 數字、第一棒是哪隊）
        → Space 播放，KTV 兩行歌詞逐字變色
        → 遮字句提前一句以金色空白牌出現在「下一句」位置
        → 遮字句前 5 秒：燈光轉紅、橫幅「下一句：紅隊 800 分」
        → 前 3 秒：右上角倒數 3-2-1（嗶聲）
        → 停住：鏡頭推近、光束收攏、鼓聲滾奏、橫幅「紅隊 接唱！」
        → 輪到的隊伍唱出整句（可要求 💡提示 或 ⏪重聽）
        → 主持人判定：
            答對（Enter）     → 牌一張張翻開（金）＋粒子爆發＋鏡頭震動＋「+800」飛向該隊
            公布答案（A）      → 牌翻開（藍）＋失敗音效，0 分
          自動輪到下一隊 → 牌翻完後繼續播放
        → 本首結束 → 下一首（→）
        → 最後：🏆 公布結果（P）→ 頒獎台
```

### 狀態

| 狀態 | 舞台 | 說明 |
|---|---|---|
| READY | ROUND N 開場 | 換歌後的待機 |
| PLAYING | KTV 歌詞逐字變色 | 播放中；遮字前 5 秒警示、3 秒倒數 |
| YOUR TURN | 金色空白牌閃紅光、橫幅「XX 接唱！」 | 停在遮字句，等待判定 |
| CORRECT / ANSWER | 翻牌、閃光、飛字 | 停留 2.2 秒後回到 PLAYING |
| FINISHED | 燈光轉暗 | 播到 `endTime` 或歌曲結束 |

### 操作

| 動作 | 舞台鍵盤 | 控制台 | 手機 |
|---|---|---|---|
| 播放／暫停 | Space | Space／按鈕 | 按鈕 |
| 答對（自動加分） | Enter | Enter／按鈕 | 按鈕 |
| 公布答案（0 分） | A | A／按鈕 | 按鈕 |
| 提示：翻一個字 | I | I／按鈕 | 按鈕 |
| 重聽：從前一句重播 | B | B／按鈕 | 按鈕 |
| 指定輪到的隊伍 | 1–6 | 1–6／點隊伍卡 | 點隊名 |
| 手動加減分 | — | −100／+100／+200／+500 | −100／+100／+200 |
| 重來這一首 | R（按兩次） | R（按兩次） | — |
| 上／下一首 | ← →（按兩次） | ← →（按兩次）、點 Round 清單 | 按鈕（點兩次） |
| 計分板顯示 | S | S／按鈕 | — |
| 公布結果（頒獎台） | P | P／按鈕 | — |
| 音效開關 | M | M／按鈕 | — |
| 舞台全螢幕 | F／F11，Esc 離開 | F／按鈕 | — |
| 結束遊戲 | H（按兩次） | 按鈕（按兩次） | — |

「按兩次」是防誤觸：歌曲進行中，這些操作要在 2 秒內按第二次才生效；READY 時一按就生效。

## 音源

| 音源 | 怎麼設定 | 優點 | 限制 |
|---|---|---|---|
| 本地檔案 | 編輯器「選擇音檔」，會複製進 `songs/` | 不靠網路、停點最準（誤差約 3ms）、有波形、燈光跟著音樂律動 | 需自備檔案 |
| YouTube | 編輯器貼網址 | 不用找檔案，分享題庫只要影片 ID | 需要網路；可能有廣告；部分影片禁止內嵌；暫停時 YouTube 會顯示影片標題；畫面改成影片＋歌詞並排（規定不能遮住播放器）；沒有波形與真實律動 |
| 音訊網址 | 編輯器填網址 | 不用存檔案 | 需要網路 |

- 一首歌可以同時設定多種音源。開始遊戲時選「本地檔案優先」或「YouTube 優先」，找不到時自動用另一種。
- **YouTube 偏移**：同一首歌的 YouTube 版本開頭常和本地檔不同，偏移量讓同一份歌詞時間兩邊共用。編輯器裡播 YouTube、在某句開唱時按「對齊 YouTube」就會自動算出來。
- 題庫檢查會標出「需要網路的歌曲」，由使用者決定要不要換成本地檔。
- 授權提醒（非法律意見）：家庭聚會不算公開演出；公司活動對多數人播放屬公開演出，要另外確認授權（例如場地是否已取得）。內嵌 YouTube 只解決取得音源的方式，不解決公開演出授權。

## 出題（歌曲編輯器）

```
1. 填歌名、歌手
2. 設定音源：選本地檔／貼 YouTube 網址
3. 帶入歌詞：
   ├ 線上搜尋（LRCLIB）：依歌名＋歌手搜，有本地檔時依長度排序，標示「有時間／純文字」
   ├ 匯入 .lrc／.txt 檔
   └ 貼上（自動判斷是 LRC 還是純文字）
   ＋ 簡→繁、清掉作詞作曲等資訊行
4. 對時間：
   ├ 有時間的歌詞 → 「全部平移」整體校正
   └ 沒時間的歌詞 → 打拍子模式：播放時每句開唱按 Space
5. 設遮字：該行按 ★ 或 M 就是整句遮（最常用）；先選取文字再按則只遮選取部分；再按一次取消
6. 精修遮字句：波形點選、[ ] 微調 ±0.05 秒、🎯 試停（從停點前 3 秒播到停點）
7. 設播放範圍（開始／結束，可「設為目前時間」）
8. 儲存（Ctrl+S）；右下即時顯示檢查結果
```

設計重點：**只有遮字句要精準**。一般句子誤差 0.3 秒內觀眾察覺不到，工具把力氣放在遮字停點的試停與微調。

編輯器快捷鍵：Space 播放、↑↓ 選句、M 整句遮字、`[` `]` 微調、P 從選取句前 1 秒播放、T 試停、Ctrl+S 儲存。

## 題庫管理與檢查

- 資料夾：預設 `文件/MillionSinger/`（`songs/`、`playlists/`），可變更到雲端硬碟或隨身碟。第一次開啟放入範例。
- 控制台可新增題庫、新增／編輯／刪除／排序歌曲。每次存檔前舊檔備份到 `playlists/.backup/`。
- 題庫格式與 v1 相容（JSON 歌曲陣列），新增欄位：`artist`、`youtube`、`youtubeOffset`。
- 檢查分兩級，題庫清單與編輯器都看得到：
  - 錯誤：找不到音檔且沒有其他音源、開始時間不早於結束時間、沒有可用歌詞、題庫格式壞掉
  - 警告：沒有遮字、遮字 `*` 沒成對、遮字句在播放範圍外、時間格式讀不了、秒數寫成 60 以上、需要網路、沒有歌名
- 有錯誤時開始遊戲會再確認；有問題的 Round 在清單上標 ⚠️。

## 手機遙控

- 控制台右上「📱 手機遙控」開啟，顯示 QR code 與網址。
- 手機頁面：Round、歌名、進度、**目前／下一個遮字的答案與倒數**、答對／公布答案／播放／切歌按鈕、各隊計分。
- 網址帶隨機 token，每次開啟都不同；不要分享給參賽者。
- 連不上時：公司 Wi-Fi 常隔離裝置，改用筆電開熱點；Linux 的 ufw、Windows 防火牆要允許 port（預設 39461）。

## 計分

- 開始遊戲時填隊伍名稱（逗號分隔），留空就不計分（仍可玩，只是不輪替、不加分）。
- 每個遮字點輪到一隊，答對或公布答案後自動換下一隊；操作者可隨時指定（1–6 鍵或點隊伍卡）。
- 分數＝**還藏著的字數 × 100**：整句 8 個字＝800 分；用一次提示翻開一個字＝700 分。提示最多用到剩一個字。
- 答對自動加分給輪到的隊伍；公布答案 0 分。部分正確等情況用手動加減分調整。
- 舞台底部計分板：輪到的隊伍有 🎤 與洋紅色光框，領先隊伍發金光。
- 🏆 公布結果：頒獎台依名次升起（冠軍在中間），燈光轉彩色、連續粒子爆發與號角音效。

## 舞台視覺與音效

- 風格：**霓虹綜藝舞台**（黑底、金色主色、洋紅與青色點綴）。選 3D 而非像素風，理由見 game-design.md。
- Three.js 3D 背景：掃動的聚光燈、發光粒子、舞台地板與光圈。
- 鏡頭與燈光跟著狀態：播放金色；警示轉紅並略為推近；停住時鏡頭推近、光束收攏到中央；答對金色爆發＋震動；公布答案藍色；結算彩虹色。
- KTV 兩行歌詞：上排靠左、下排靠右輪替，唱過的字變金色（依句長估算速度）；遮字句提前一句以空白牌預告並輕微浮動。
- 空白牌：金色立體牌，揭曉時依序 3D 翻開；提示翻開的字是白色、答對金色、公布答案藍色。
- 本地音檔時，上方律動條與燈光亮度跟著真實頻譜；YouTube 時用動畫代替。
- 音效全部即時合成（沒有音檔與授權問題）：倒數嗶聲、停住重擊＋鼓聲滾奏、翻牌聲、答對琶音、答錯下行音、提示叮聲、加分金幣聲、Round 開場呼嘯、結算號角。M 鍵開關。
- WebGL 無法啟動時自動退回純黑背景，遊戲照常進行。

## 已知限制

- YouTube 暫停時會顯示影片標題，無法遮蓋；影片中途的廣告會打斷遊戲。正式場合建議用本地檔。
- 停點精準度只保證程式下暫停的時間點（本地檔約 ±10ms）；音效卡緩衝與 LRC 本身的誤差靠 0.1 秒提早量與試停調整。
- KTV 逐字變色是依句長估算，不是真正的逐字時間；唱得特別快或拉長音的句子會不同步。
- 手機遙控只有切歌，沒有重來、結束遊戲、公布結果（避免主持人誤觸）。
- 計分沒有存檔，結束遊戲後歸零；舞台視窗重新載入（Ctrl+R）也會從第一首重來。
- 安全設定沿用 v1（`nodeIntegration`、`webSecurity: false`），只載入本機檔案，未收緊。
- 舞台視窗在 Hyprland 等平鋪式視窗管理器下會被並排縮小，要按 F 全螢幕。

## 待討論

- 計分規則要不要可調（每字分數、後面的 Round 加倍、答錯扣分）？
- 要不要搶答模式（例如手機按鈕搶答）？
- 每個遮字點要不要能個別調整提早量（目前全域 0.1 秒）？
- 計分與進度要不要存檔，可中途關掉再繼續？
- 手機遙控要不要能直接選 Round、重來？
- 舞台風格（顏色、字體、3D 強度）是否要可設定或有多套主題？
- 要不要收緊 Electron 安全設定（preload＋contextIsolation）？
- 是否需要 Windows／Mac 實機驗證後再發佈（CI 目前只在 main 分支觸發）？

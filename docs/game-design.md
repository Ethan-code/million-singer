# 遊戲設計（v2.1）

v2.0 是把 v1 的機制搬到新架構；v2.1 從「怎麼玩才好玩」重新設計。這份記錄發想、收斂後的決定與理由。

## 好玩的核心是什麼

一局的情緒曲線：**一起唱 → 緊張 → 停住 → 接唱 → 揭曉爆發**。每個功能都要服務這條曲線，不服務的就砍。

| 階段 | 要的感覺 | 對應設計 |
|---|---|---|
| 一起唱 | 全場跟著唱、有節奏感 | KTV 兩行歌詞、逐字變色 |
| 緊張 | 「要來了！」 | 下一句預告就出現空白牌；倒數 3-2-1；燈光轉紅、心跳音效 |
| 停住 | 聚光燈打在參賽者身上 | 音樂停、鏡頭推近、大字「輪到 紅隊 接唱」、鼓聲 |
| 接唱 | 壓力與策略 | 整句空白牌；可用提示（翻一個字，少拿分）；可重聽 |
| 揭曉 | 爆發、公平感 | 牌一張張翻開、答對金色爆發＋音效＋分數飛向隊伍；答錯藍色＋失敗音效 |
| 結束 | 有收尾、有贏家 | 頒獎台結算畫面 |

## 收斂後的決定

### 遮字以「整句」為主
- 唱到遮字句前停住，整句變成空白牌，參賽者要唱出整句。
- 仍支援只遮一部分（`*一心*一德`），但編輯器預設「整句遮」：該行按 ★ 不選字就是整句。
- 遮字句會**提前一句出現在預告行**（KTV 的下一句位置），全場看得到「下一句是空白」——緊張感從這裡開始。

### KTV 式歌詞
- 兩行輪替：正在唱的句子＋下一句，像 KTV 一樣上下交錯。
- 正在唱的句子逐字變色（金色），速度依句子長度與下一句時間估算（LRC 只有句首時間，沒有逐字時間）。

### 輪流與自動計分
- 有隊伍時，每個遮字點輪到一隊（自動輪替，操作者可改）。
- 分數＝**還藏著的字數 × 100**。整句 8 個字＝800 分。
- 答對：分數自動加給輪到的隊伍。公布答案（答錯）：0 分。
- 部分正確等特殊情況，操作者用手動加減分調整。

### 提示與重聽（策略）
- **提示**：翻開下一個字，這個字不計分（8 字的句子用一次提示＝最多 700 分）。
- **重聽**：從前一句重播到停點，不扣分。
- 這兩個給參賽隊伍「要不要求救」的選擇，是好玩的小決策。

### 演出
- 倒數 3-2-1 大字（遮字句前 3 秒），搭配嗶聲。
- 停住時：鏡頭推近、光束收攏到中央、鼓聲滾奏。
- 答對：牌依序翻開、金色粒子爆發、鏡頭震動、勝利音效、「+800 紅隊」飛字。
- 答錯：牌翻成藍色、失敗音效。
- 所有音效用 Web Audio 即時合成，不用音檔（沒有授權問題），可按 M 靜音。

### 結算
- 控制台「🏆 公布結果」：舞台切到頒獎台，各隊依名次升起，冠軍彩帶。

### 視覺風格：霓虹綜藝舞台
- 選 3D 而不是像素風：歌詞是主角，CJK 大字在像素風下可讀性差；3D 舞台燈光更有「綜藝節目」的臨場感。
- 黑底、金色主色、少量洋紅與青色點綴；Three.js 負責舞台、燈光、鏡頭運動與粒子，DOM 負責清晰的文字。

## 砍掉／延後
- 搶答模式：需要額外的搶答硬體或手機搶答流程，延後。
- 逐字精準時間（增強型 LRC）：出題成本太高，用估算代替。
- 道具卡的更多種類（跳過、雙倍）：先只做提示與重聽，玩過再加。
- 計分存檔：延後。

# 改版規劃

改版前的需求與流程討論紀錄。先把流程與功能談定，再進入實作。

採**最小可行版本**策略：先做 v1.1，把既有功能整理收斂、修穩，不加新玩法；其餘想法都收進 Backlog，等 v1.1 完成後再挑。

## 設計原則

- **功能導向，不鎖場景**：不做「尾牙模式」「家用模式」這種寫死的分流，而是提供各項功能並說明取捨，由使用者依場景組合。
- **現場穩定優先**：任何會打斷畫面的東西（系統對話框、誤觸跳頁、未預期的錯誤）都要避免；能事前發現的問題就在上台前檢查出來。
- **app 不附帶任何音源**：題庫只存歌詞、時間點與音源參照，音檔由使用者自備。

## 現況（v1.0.0）

- Electron 單頁 app，邏輯全在 `index.html`。
- 掃描 `playlists/*.json` 選題庫；音源為 `songs/` 本地檔或 `url`，可設 `startTime` / `endTime`。
- LRC 歌詞，全螢幕只顯示當前一句；`*…*` 包住的字顯示為 ★（中文一字一顆、英文一單字一顆）。
- 播到遮字句自動暫停，遮字前 5 秒紅框閃爍警示；只有「答對（揭曉）」一種判定。
- 快捷鍵：Space 播放／暫停、Enter 答對、← → 切歌、R 重來、H 回首頁。
- electron-builder 打包 Windows / macOS，GitHub Actions 建置。

已知問題：

- 主持人看不到答案；沒有答錯／公布答案／重聽流程；沒有計分與隊伍。
- 停點用 50ms `setInterval` 輪詢，加上 pause 延遲可能晚停約 0.1 秒，漏出答案第一個音。
- 錯誤訊息用 `alert`；H、← → 單鍵即生效，容易誤觸。
- 「CORRECT」狀態只停 0.25 秒；歌名揭曉後一直留在畫面上。
- `songs/`、`playlists/` 打包在 app 內，mac 版在 `.app` 裡，使用者難以自行加歌。
- `nodeIntegration: true`、`contextIsolation: false`、`webSecurity: false`。
- forge 與 electron-builder 並存；mac 設定指向不存在的 `build/entitlements.mac.plist`。

### 音源

一首歌可同時設定多種音源，各自記錄時間偏移（同一首歌不同版本的開頭時間不同，校正一次即可沿用整份對軌）。

| 音源 | 優點 | 限制 |
|---|---|---|
| 本地檔案 | 不靠網路、無廣告、停點最準 | 需自備檔案 |
| YouTube 內嵌（IFrame Player API） | 不用找檔案、分享題庫只需影片 ID | 播放器必須可見且不可被遮蓋（畫面需改為影片＋歌詞並排）；可能有廣告；部分官方影片禁止內嵌；依賴網路；影片可能下架；MV 可能有燒錄字幕洩題；拿不到音訊資料，無法畫波形 |

- 不支援下載 YouTube、串流平台擷取等違反服務條款的來源。
- 上台前檢查會標示「需要網路的歌曲」，由使用者決定要不要換成本地檔。
- 授權提醒（非法律意見）：家庭與一般社交圈內播放不算公開演出；公司活動等對「特定之多數人」播放屬公開演出，需另行取得詞曲（MÜST）與錄音（ARCO／RPAT）授權，或確認場地是否已有授權。內嵌 YouTube 只解決取得音源的方式，不解決公開演出授權。

### 畫面與角色

- **主畫面**：給觀眾看的遊戲畫面，永遠不顯示答案。
- **操作者控制台（選用）**：有延伸螢幕時開在第二個視窗；單螢幕時只用快捷鍵，控制 UI 平時隱藏。
- **手機小抄（統一方案）**：app 開區網服務並在畫面顯示 QR code，手機掃描開啟。顯示當前題號、遮字答案、下一題預告，之後可加分數與判定按鈕。
  - 網址帶 token，避免同網段的人偷看。
  - 備案：區網連不上時（公司 Wi-Fi 常有裝置隔離）改用筆電熱點，或匯出 PDF 小抄。
  - 這個本地服務也一併解決 YouTube 內嵌在 `file://` 下報錯的問題。
- 主持人與操作者可以是不同人：主持人拿手機看答案（與判定），操作者負責播放。

### 製歌流程

這個遊戲**不需要整首逐句精準**：一般歌詞誤差約 0.3 秒觀眾察覺不到，真正要精準的只有「遮字句停點」與片段起訖。因此工具重心放在遮字點精修，而非逐句對軌。編輯器放在同一個 app 內，作為另一個畫面。

```
1. 選音源：本地檔案（可解碼畫波形）/ YouTube 連結（無波形）
2. 抓歌詞
   └ LRCLIB 依歌名＋時長搜同步歌詞；或匯入 .lrc；或貼純文字
   └ 自動清理：簡轉繁（OpenCC）、刪作詞作曲等資訊行
3. 粗對
   └ 有同步歌詞 → 整體 offset 校正（對準一句，全部平移）
   └ 純文字 → 打拍子模式：空白記錄每句開頭、Backspace 撤銷、可 0.75x
4. 剪片段：波形上拖 start / end，或點歌詞設起訖；可選淡入淡出
5. 出題：直接點字設為遮字（中文以字、英文以單字為單位），即時預覽 ★
6. 精修遮字點
   └ 停點獨立存一個時間（預設＝句首）
   └ 波形放大、±0.05s / ±0.01s 微調
   └ 「試停」：從停點前 5 秒播到停點，可反覆
7. 預覽：用正式遊戲畫面跑一次，或跳到某遮字點前 5 秒
8. 存檔 → 自動檢查；歌曲有製作狀態（未對軌 → 已粗對 → 已出題 → 已試停確認）
```

- 後期選項：WhisperX 一類的強制對齊＋人聲分離（Demucs）自動對軌。需要額外 Python 環境、中文歌準確度普通，等手動流程好用後再評估。
- 歌曲記錄音檔時長，匯入時長度對不上就提示可能是不同版本。
